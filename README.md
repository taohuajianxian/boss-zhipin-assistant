# BOSS直聘自动投递 Skill

**把投简历这件苦差事，交给你的 Agent。**

你定方向，它去干活：一个个岗位点开、把 JD 从头读完、判断对不对口，对口的才投。不对口的、外地的、标题蹭词的，统统拦下来，不浪费你的沟通次数。投了哪些、为什么投，事后有一份汇报给你看，清清楚楚。

## 它和脚本有什么不一样

- **它真的在「看」岗位**：每个岗位都读原文、逐项对职能、地点、薪资，不是拿关键词碰运气
- **节奏像真人**：一个一个来，不批量乱投
- **越用越对味**：你的偏好、黑名单、薪资底线都记在个人档案里，判定按你的标准来
- **更新不用你操心**：网页结构变了，云端自动下发新版，你这边什么都不用动

## 怎么装

一句话：下载 zip，丢给任意一个 Agent，跟它说「给我装这个 skill」就行。

能装明白的 Agent，后面的投递任务才带得动；连装都装不明白的，也不用指望它替你投简历了。

装好当天先免费体验，顺手不顺手，跑一天就知道。

## 开始之前

你需要准备的就这些：

- 一个能干活的 Agent（平时帮你跑任务的那种就行）
- Chrome 里登录好你的 BOSS直聘
- **Kimi WebBridge**：Agent 靠它操作你的 Chrome，这是必需的，缺了跑不起来；装 skill 的时候 Agent 会带你一起装好
- 想好你要找什么：城市、方向、薪资底线——填进个人档案，Agent 会带着你填

## 一句提醒

自动化投递有平台风控风险，节奏自己把握；真遇到验证，它会停下来等你，不会硬闯。
